# 네이 배너 스튜디오 · GitHub Pages 배포용

배너 편집, 스티커 글씨, 구름, 도형·UI 장식, 원형 프로필 영상 편집을 지원하는 브라우저 편집기입니다.
별도 서버, API 키, 설치·빌드 과정 없이 GitHub Pages로 공개할 수 있습니다.

## 처음 공개하기

1. GitHub에 로그인하고 새 저장소를 만드세요. 예: `nei-banner-studio`.
2. 무료 공개 배포라면 저장소를 Public으로 만드세요. 기존 다른 사이트의 저장소 대신 새 저장소를 권장합니다.
3. 이 ZIP을 컴퓨터에서 압축 해제하세요.
4. 저장소에서 **Add file → Upload files**를 선택하세요. 새 빈 저장소에서는 **uploading an existing file** 링크를 누르세요.
5. 압축을 푼 폴더 안의 파일 전체를 올리고 **Commit changes**를 누르세요.
   - ZIP 파일 자체를 올리는 것이 아닙니다.
   - 저장소 첫 화면에 `index.html`과 `.js`, `.css` 파일들이 바로 보여야 합니다.
6. **Settings → Pages → Build and deployment**에서 다음과 같이 선택하세요.
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
   - **Save**
7. 게시가 완료되면 Pages 설정에 표시되는 주소를 공유하세요.
   일반적인 주소 형태: `https://계정명.github.io/저장소이름/`

공식 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 공개 후 확인

- 배너 편집 탭에서 글자 추가, 한글 입력, 글꼴 선택을 확인하세요.
- 스티커 스타일을 적용하고 PNG 저장 결과를 확인하세요.
- 도형·구름·UI 소재를 추가하고 이동·크기·투명도 조절을 확인하세요.
- 원형 움짤 만들기에서 짧은 영상을 넣고 APNG/GIF 저장을 확인하세요.
- 다른 브라우저나 시크릿 창에서도 공개 주소가 열리는지 확인하세요.

## 나중에 수정하기

이 대화에 저장소 주소와 바꿀 내용을 알려 주세요. 수정 파일을 같은 저장소의 같은 위치에 덮어쓰고 커밋하면 기존 주소에 업데이트됩니다.
저장소 이름을 유지하세요. 새 파일 추가·삭제가 필요한 업데이트는 함께 제공되는 설명대로 반영하세요.
반영이 늦으면 Actions 탭에서 배포 상태를 확인하세요. 작업 중인 결과물을 먼저 저장한 후 새로고침하세요.

## 사용 시 알아둘 점

- 이미지와 영상은 브라우저에서 처리합니다. 서버에 작업물을 저장하는 기능은 없습니다.
- 새로고침이나 탭을 닫기 전에 결과물을 내려받으세요. 편집 상태 자동 복원은 제공하지 않습니다.
- 추가 글꼴은 Google Fonts와 jsDelivr에서 불러오므로 인터넷 연결이 필요합니다.
- 글꼴 로딩이 실패하면 PNG 저장을 중단하고 안내합니다. 외부 서비스 차단 여부를 확인하세요.
- 실제 GitHub 공개 URL에서의 동작 확인은 업로드 후 필요합니다.
- 파일 선택·영상 지원은 브라우저에 따라 차이가 있습니다. 최신 Chrome/Edge 사용을 권장합니다.
